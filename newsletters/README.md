# The Creditt Report (LinkedIn newsletter)
Monthly edition drafted by a scheduled task. Banner: run `python3 tools/make_news_banner.py newsletters/YYYY-MM-banner.json` from the repo root (1920x1080, Sid's headshot in brand/sid/headshot.png, NO Creditt logo or website on the banner).
JSON keys: headline = list of [text, "w"|"y"] lines (white/yellow, max ~22 characters per line, 3 lines), subtitle = 2 lines (max ~48 characters each), chips = 4 x [glyph, line1, line2] (glyph one of % ↓ ↑ ✓ $ 5% or a short number; line text max ~14 characters).
November 2026 edition = reference for tone and structure (intro, 3 numbered topic sections, checklist, dates to watch, sign-off with 0402 993 545 and creditt.com.au, general information disclaimer).
